# 2.0.0 — Animation, emoticons and material updates

**Recorded local delivery · 2026-09-16**

## Changes

- Changed toon outlines to follow evaluated skin and cloth, and used authored lit/shadow colour textures without a global emission overlay.
- Separated disconnected garments from the body and added editable cloth pins and body collisions.
- Added Embers, Orbit, Rain and Still backgrounds, interface transitions and reduced motion; updated dark dropdowns and rounded controls.
- Added animation FPS resampling from 1–240, including fractional rates, while retaining duration.
- Added animated emoticons using packed sprite sheets and stepped UV animation.
- Added source-icon PNG export below Style, with a base-icon fallback.
- Added emote audio extraction at the time. This was removed in 2.0.1.
- Fixed texture-decoder initialization and installer payload embedding; moved extraction off the UI thread.

## Validation and limitations

The archived readme records checks on Marge, Aang, Bonejamin, Bonesy, Blue House and Baffled Aang, plus saved-scene and native UI checks. These historical checks did not establish full gameplay-reactive, Niagara or original Unreal cloth support.

## Installation

This historical build used the Fortnite Porter Studio name and included its Windows x64 runtime. Follow the current README when installing a newer build.
