# Available builds

The [GitHub Releases page](https://github.com/oozycloud/oozys-Fortnite-Porter/releases) contains the preserved builds. Use the newest beta for current fixes. Historic installers are archived as originally built and may have known compatibility or export problems.

| Version | Preserved downloads |
| --- | --- |
| 2.1.0 | Original installer (existing legacy release) |
| beta 0.1.1 | Original installer |
| beta 0.2.1 | Installer, portable app, recovered source backup |
| beta 0.3.1 | Installer, portable app, source backup |
| beta 0.4.1 | Installer, portable app, source backup |
| beta 0.4.2 | Installer, portable app, source backup |
| beta 0.4.3 | Installer, portable app, source backup |
| beta 0.4.4 | Installer, portable app, source backup |
| beta 0.5.0 | Installer, portable app, source backup |
| beta 0.6.0 | Installer, portable app, source backup |
| beta 0.7.0 | Installer, portable app, source backup |

Each newly uploaded beta release includes SHA-256 checksums. Extract the entire portable ZIP before opening its launcher; keep the launcher and `app` folder together.

Binaries for 1.0.0–2.0.1, 2.2.0 and beta 0.0.1 were not found in the surviving files. Their release notes remain available, but they are not presented as downloadable builds. No old release has been recreated by renaming a newer executable.
