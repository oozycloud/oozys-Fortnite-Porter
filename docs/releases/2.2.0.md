# 2.2.0 — oozy's Fortnite Porter branding and updates

**Recorded local delivery · 2026-09-17**

## Changes

- Renamed the app to oozy’s Fortnite Porter and added its orange icon and matching installer.
- Added manual GitHub release checks and optional startup checks.
- Introduced a native root launcher with runtime and support files under app/.
- Added installation detection, an Update action, rollback on failed replacement and protection against updating a running installation.
- Added Traversal / Static traversal choices for traversal emotes, including Business Hips.
- Retained the separate-emote importer, dark controls, animated themes and independent multiple selection.
- Adjusted the procedural skybox backdrop so it does not block world lighting.

## Validation and limitations

The preserved release report records 61 installer/update checks, 10 packaged-installation checks, 13 asset exports and six separate-emote comparisons. Marge’s dress still clips in raised-knee poses; other shader, effect and inferred-physics limitations remain. This was a local development delivery and was subsequently replaced by the beta numbering reset.

## Installation

This build used `oozys-Fortnite-Porter-Installer (2.2.0).exe` and the root launcher plus `app` layout. It is superseded by beta 0.0.1.
