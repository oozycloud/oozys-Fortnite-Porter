# 2.1.0 — Packed models and separate-emote import

**Recorded local delivery · 2026-09-16**

## Changes

- Added the Blender Porter panel to apply separately exported emotes to existing skin rigs, with source-pose retargeting and support for earlier Porter emote files.
- Restored the previous action if an emote import fails.
- Embedded source animation data inside new animated Blender exports.
- Added a packed Blender format selector, an importer installation button and a manual PorterEmoteTools.zip.
- Reconstructed Astro Jack SICKO MODE’s cyan body appearance from its switch, mask and colour, while retaining separate animated coat effects.
- Kept emote exports silent and retained animated-material speed across FPS changes.

## Validation and limitations

The importer requires Blender 4.4 or newer; this build was tested with Blender 5.1. Astro Jack’s cyan contour is an approximation. Marge dress clipping and incomplete gameplay-reactive/particle conversion remain documented.

## Installation

This historical build used the Fortnite Porter Studio name and included its Windows x64 runtime. Follow the current README when installing a newer build.
